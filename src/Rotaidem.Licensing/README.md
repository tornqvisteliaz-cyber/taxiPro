# Rotaidem.Licensing

Rotaidem's licence keys and online activation against rotaidem.com. Copied from HeavyPro
(`src/Rotaidem.Licensing`, which copies it from `rsg.com` `licensing/`, branch
`claude/lucid-tesla-liazv2`, commit `40221c1`).

GroundPro changes, kept small so the copies stay easy to compare:

- `LicensedProduct.Name` replaces the word "HeavyPro" in user-facing messages.
- `LicenseKey.GroundProPrefix` (`GPRO`).

Behaviour, the server protocol and the token checks are unchanged.
